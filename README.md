# My Home Hub

두 사용자가 하나의 반응형 웹 인터페이스에서 각자의 Synology NAS 파일과 Windows 데스크톱, 중앙 Ubuntu MINI PC Server 상태를 안전하게 확인하는 개인용 홈 인프라 관리 서비스입니다.

## MVP 핵심 기능

- 폐쇄형 사용자 로그인과 권한 관리
- 사용자별 Synology NAS 연결
- NAS 폴더 탐색, 파일명 검색 및 다운로드
- Ubuntu MINI PC Server 상태 확인
- 사용자별 Windows 데스크톱 상태 확인과 Wake-on-LAN
- 주요 활동 및 보안 감사 기록

## 기술 구성

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Spring Boot, Java 21, Gradle
- Database: MariaDB
- Deployment: Docker Compose

## 현재 상태

MVP 설계 검토 및 개발 환경 구성 단계
